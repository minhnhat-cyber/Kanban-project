# Kanban Board with Dashboard

## Project Description
A React JS Kanban Board application that allows users to create, edit, delete, and manage tasks across TO DO, DOING, and DONE columns. Task and category data are stored in Local Storage. The dashboard presents task summaries and charts.

## Features
- Create, edit, delete tasks
- Move tasks between TO DO, DOING, and DONE
- Manage categories
- Assign responsible persons
- Store data using Local Storage
- Dashboard with summary cards and charts
